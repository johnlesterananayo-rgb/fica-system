# FICA - Student Record Management System (SRMS)

An AI-powered Student Record Management System designed for Fidelis Children Academy to centralize records, streamline administrative workflows, and provide actionable student analytics.

---

## 📁 Repository Structure

The frontend consists of modular interfaces organized by feature:

* `login/` – Authentication and access portal
* `dashboard/` – Administrative overview and metric summaries
* `student/` – Student profile management, records, and directory
* `calendar/` – Academic schedule, events, and deadline tracking
* `reports/` – Generated student progress reports and exports
* `request/` – Document processing and administrative request logs
* `logs/` – System activity and audit trails
* `settings/` – System configuration and preferences
